# RepositoryFinder
A repository finder to find suitable repositories for your data 


# how to run it 
What you need: R and RStudio installed on your computer.

- Step 1 – Download the app Go to https://github.com/LTER-LIFE/RepositoryFinder Click the green "Code" button, then "Download ZIP". Unzip the folder anywhere on your computer. (Familiar with Git? You can also clone the repository.)

- Step 2 – Open the app In the unzipped folder, open the file app.R in RStudio.

- Step 3 – Install the required packages (first time only) Copy this line into the RStudio console (bottom-left panel) and press Enter: install.packages(c("shiny", "bslib"))

- Step 4 – Start the app Click the "Run App" button at the top right of the app.R script. 

The Repository Finder opens in a new window. Click "Open in Browser" if you prefer a browser tab.
